## 📖 Overview

**Savoury** is a clean, multi-page culinary web platform designed to deliver an engaging gourmet dining experience. It features interactive recipe curation, dynamic ingredient exploration, occasion-based event catering, and a modern authentication interface.

---

## 🌟 Core Features

- **Responsive Multi-Page Architecture**:
  - `index.html`: Hero landing page with featured dishes, trending recipes, and chef specials.
  - `recipes.html`: Interactive recipe catalog with category filtering (Appetizers, Mains, Salads, Pastas).
  - `ingredients.html`: Fresh ingredient sourcing guide and nutritional highlights.
  - `occasions.html`: Tailored menu planning for weddings, corporate galas, and celebrations.
  - `about.html`: Culinary philosophy, team background, and restaurant story.
- **Client-Side Authentication (`auth.js`)**:
  - Modal login/signup flows with real-time input validation and credential handling.
- **Modern UI & Visual Design (`style.css`)**:
  - Custom CSS Flexbox and Grid layouts.
  - High-resolution visual media, subtle hover animations, and cross-browser responsiveness.

---

## 🛠️ Tech Stack

- **Markup:** Semantic HTML5 elements (`<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`)
- **Styling:** Pure CSS3 (Custom Variables, Flexbox, CSS Grid, Media Queries, Keyframe Animations)
- **Scripting:** Modular JavaScript (ES6+ Event Listeners, DOM Manipulation, Modal State Control)
